# Student Management System

A console-based Student Management System developed using Python. This project allows an administrator to manage student records through a menu-driven interface with JSON-based data persistence.

## Features

- Admin login with limited login attempts
- Change admin username and password
- Add new student records
- View all registered students
- Search students by ID
- Update student information
- Delete student records
- Input validation and error handling
- Save and load student records using JSON
- Separate modules for student and admin operations

## Technologies Used

- Python
- JSON
- PyCharm

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the Student Management System folder.
4. Run `main.py`.

## Data Storage

The application uses JSON files to store student records and administrator credentials locally.

**Note:** The JSON files containing personal records and credentials should not be uploaded to GitHub.
