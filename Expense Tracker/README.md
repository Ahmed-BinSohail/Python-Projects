# Expense Tracker

A simple Python-based Expense Tracker that allows users to manage and track their daily expenses.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Search expenses by category
- Save expenses using JSON
- Load previously saved expenses
- Input validation and error handling

## Technologies Used
- Python
- JSON
- PyCharm

## How to Run
1. Clone or download this repository.
2. Open the `Expense-Tracker` folder.
3. Run `main.py`.
