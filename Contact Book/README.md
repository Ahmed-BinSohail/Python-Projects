# Contact Book

A simple Python-based Contact Book application that allows users to manage their contacts through a command-line interface.

## Features

- Add new contacts
- View all saved contacts
- Search contacts by name (case-insensitive)
- Update contact phone numbers
- Delete contacts
- Prevent duplicate phone numbers
- Allow multiple contacts with the same name
- Save contacts using JSON
- Automatically load previously saved contacts
- Handle missing and corrupted JSON files
- Validate menu input

## Technologies Used

- Python
- JSON
- PyCharm

## Project Structure

```text
Contact Book/
│
├── main.py
├── contacts.json
└── README.md
```

## How to Run

1. Clone this repository.
2. Navigate to the Contact Book directory.
3. Run the following command:

```bash
python main.py
```

4. Use the menu to manage your contacts.
